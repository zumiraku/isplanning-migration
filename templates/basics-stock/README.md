## なぜ控えを取るのか

2026-09-07 まで、**このコードはリポジトリのどこにもありませんでした。**
存在するのはコンソールの入力欄の中だけです。

つまり、誰かが箱を全選択して消したら、**復元する手立てがありませんでした。**
デザイン一括バックアップの保存枠は5件とも埋まっていて（`design-backup.md`）、
そこからも取れません。

こちらのブロックを貼り直すたびに、この67行の隣で作業しています。控えが
無いまま触り続けるのは、綱渡りです。
