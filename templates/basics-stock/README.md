# Basics 標準のコード — 箱に同居しているもの

**ここにあるのは、こちらが書いたものではありません。** クリエイターモードの
`全ページ共通` の箱に、Basics テンプレート由来のコードが同居しており、その
控えです。

## なぜ控えを取るのか

2026-09-07 まで、**このコードはリポジトリのどこにもありませんでした。**
存在するのはコンソールの入力欄の中だけです。

つまり、誰かが箱を全選択して消したら、**復元する手立てがありませんでした。**
デザイン一括バックアップの保存枠は5件とも埋まっていて（`design-backup.md`）、
そこからも取れません。

こちらのブロックを貼り直すたびに、この67行の隣で作業しています。控えが
無いまま触り続けるのは、綱渡りです。

jQuery（`$`）を前提に書かれています。**こちらのブロックより先に置くと、
`$ is not defined` でファイルごと止まり、こちらのコードが1行も動きません。**
だから順番は「こちらが先、Basics が後」です。

やっていること: グローバルナビのドロップダウン、記事タイトルの開閉、
検索ボックスの Enter、Web Font Loader の読み込み。**まだ作り直していない
4つのページ種別**（商品レビュー一覧・投稿／まとめ買い割引／会員制・年齢確認）が
これに依存しています。消せません。
