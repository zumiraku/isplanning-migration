## category_title.tpl — カテゴリ独自タイトル606件の表

**使いません。** クリエイターモードでも `$page.title` がカテゴリ独自タイトルを
そのまま返すことが、実サイトで確認できたためです（2026-09-05）。

### どうやって分かったか

`_shell-head.tpl` は同じページで2か所にタイトルを出しています。

```html
<title><{$module.category_title}></title>          ← こちらの表
<meta property="og:title" content="<{$page.title}>">  ← プラットフォームの値
```

**この2つを同じページで比べれば答えが出ます。**

| カテゴリ | 一致 |
|---|---|
| ct5 | 同一 |
| all_items | 同一 |
| ct573 | **違う** — こちらが全角スペースを半角に潰していた |
| ct668 | `$page.title` が `■■■` を返す。現行サイトの値そのもの |
| ct640 / ct649 / ct667 | いずれも独自タイトルが返る |

`$page.description` も同様に独自の説明文を返します。

### つまり

- **C4（カテゴリ独自タイトル・説明文が失われる）は成立しません。**
  607件も601件も、最初から失われていませんでした
- 86KBのモジュールは不要で、**31件のタイトルをわずかに劣化させていました**
  （生成時に `\s+` を半角スペース1個へ正規化していたため、全角スペースが消える）

### なぜ消さずに残すのか

`$page.title` が独自タイトルを返すことは**リファレンスに書かれていません。**
実測で分かったことです。仕様が変わったり、別の店舗で挙動が違ったりしたときに、
この表があれば1回の貼り付けで戻せます。

再生成: `sh tools/build-category-titles.sh`
検証:   `sh tools/check-category-titles.sh` / `sh tools/check-category-title-render.sh`

戻す場合は `_shell-head.tpl` の `<title>` 行を `<{$module.category_title}>` に
差し替えて、この表をモジュール `category_title` に登録します。

### ct668 のタイトルは直したほうがよいです

現行サイトのタイトルが `■■■` です。テンプレートで小細工するより、**管理画面の
カテゴリ設定で直す**のが正しい直し方です。データの問題であって、
テンプレートの問題ではありません。
