# クリエイターモードの「保存」が反映されない — 問い合わせ材料

2026-09-09 作成。**貼り付け作業を止めた理由と、その根拠**をまとめたものです。
そのままサポートへ送れる文面を末尾に付けています。

---

## 起きていること

デザインセット `発見マーケット_移行版` の **ページ種別「特定商取引法」**の
HTMLを貼り替えて `保存` を押しても、**サーバー側の内容が変わりません。**

- `保存` を押してもエラーは出ません
- `F5` でページを読み込み直し、同じページ種別を開くと、**箱の中は前の内容**
- `👁 プレビュー` の結果も前の内容

同じ症状が、**5つのページ種別で同時に**起きています。
（商品カテゴリー / 商品詳細 / 会社概要 / 利用案内 / 特定商取引法）

---

## 「保存されていない」と判断した根拠

### 1. 配信されるHTMLの中身

貼ろうとしているHTMLには、表に18行目の `サイト名称` があります。
プレビューで配信されたHTMLには **17行しかなく、`サイト名称` がありません。**

```
貼るHTML          18行  サイト名称あり  引き渡し時期「10日以内」
配信されるHTML     17行  サイト名称なし  引き渡し時期「7日以内」
```

### 2. 資産URLのタイムスタンプが動かない

プレビューHTMLが読み込むCSSのURLは、3回とも1文字も同じでした。

```
06:53  /view/asset/user-5-1-13-42769537780f584a21db0abe69c8746f.css?ptk=…&6aa0f4759a558
07:36  同じ
08:05  同じ
```

### 3. 途中で管理画面のセッションが切れていました

07:38 にブラウザから保存した「テンプレート選択・編集」のタブは、
**中身がログイン画面**でした。

```html
<link rel="canonical" href="https://console.makeshop.jp/login" />
```

タブの見出しは「テンプレート選択・編集」のままです。
**画面は編集画面に見えたまま、サーバーとの接続だけが切れます。**

その後ログインし直して貼り直しても、症状は変わりませんでした。

---

## こちらで潰した可能性

| 疑ったもの | 結果 |
|---|---|
| ブラウザのキャッシュ | `Ctrl+Shift+R` でも変わらず |
| プレビューのトークン切れ | 別ページ種別は正しく描画されるので生きている |
| 4バイト文字（絵文字）を含むこと | **前に保存できた版のほうが多い**（6個 → 1個） |
| ファイルが大きすぎる | 7,623 バイト・174行。前に保存できた版は 5,294 バイト |
| タグの閉じ忘れ | 1件あったので閉じた（お支払い方法の `<td>`）。症状変わらず |
| モジュールIDの誤り | 6件とも正しいことを確認済み |
