## 一覧が縦に並んだ理由 — 描画器の側でした

移植した一覧は「4件ごとに `<tr>` を入れる」書き方です。

```
<{if $smarty.section.i.index % 4 == 0}><tr><{/if}>
```

`tools/render-smarty.js` に **`%` 演算子が実装されていません**でした。
条件が常に undefined になり、`<tr>` が1つも出ません。**実機のSmartyは
`%` を解釈します** ── テンプレートは正しく、描画器が追いついていない
だけでした。あやうく「テンプレートの不具合」として直すところでした。

描画器に `*` `/` `%` を足しました。

## 合計金額の単位

元テンプレートはこう書いています。

