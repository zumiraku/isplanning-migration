## テンプレートを、貼らずに検証できるようにしました — 2026-09-05

`tools/render-smarty.js` が、テンプレートを**こちらで実行**して出力HTMLを出します。
Smartyそのものではなく、これらのテンプレートが実際に使っている構文だけを実装した
ものです。

### なぜ必要だったか

テンプレートの不具合が、**ひとつ残らず「貼って、プレビューして、目で見る」まで
分かりませんでした。**

| 不具合 | 見え方 |
|---|---|
| `$item.breadcrumb_list` が存在しないタグだった | パンくずが丸ごと消えた |
| ギャラリーが `$item.multi_image` だけを見ていた | サブ画像1枚。スワイプするものが無い |
| 点のHTMLがどこにも無かった | CSSはあるのに一度も出ない |

**Smartyは知らないものを黙って捨てます。** 間違ったタグだらけのテンプレートでも、
きれいなページとして描画され、あるべきものが無いだけの状態になります。ソースを
読んでも気づけませんし、管理画面で行数を数えても正しく見えます。

### この道具にできないこと

**タグ名が実在するかは判定できません。** それはリファレンスと実機プレビューでしか
分かりません。分かるのは「与えたデータをテンプレートがどう扱うか」で、繰り返し
間違えてきたのはそちらです。

### 追加した検査

```
tools/check-gallery.sh                  商品詳細を3つの商品の形で描画して数える
tools/check-category-title-render.sh    タイトル分岐を5つの形で描画して読む
```

どちらも `check-all.sh` に入っています。とくに後者は、`ct5` で確認して
「606件が生きている」と誤って報告した件の再発防止です。ct5は表とルールの結果が
一致するので、**表が無視されていても同じ文字が出ます。** 判定に使えるのは
`ct573` のように両者が食い違う形だけで、それを検査に固定しました。

「パンくずの先頭がホームだったら」という**未検証のまま書いていた逃げ**も、
