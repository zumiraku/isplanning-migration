## 🔴 いま残っている最大の技術的問題

貼り終えたページの中に、**旧URLを指すリンクが379本**あります（57ファイル）。

```
31本  /html/page9.html
30本  /html/page8.html
29本  /html/page4.html
28本  /html/page5.html
18本  /html/page2.html
```

フリーページのURLは `/view/page/pageNN.html` になったので、**この379本はすべて
404になります。** 最も参照されているページほど、壊れるリンクが多い状態です。

### 先に確かめるべきこと: URL一括設定

CSVで任意URLを付与する機能です（機能一覧にある別機能）。ここで
`/html/page9.html` を割り当てられるなら、**379本は1本も直さずに済み**、
82ページの検索評価もそのまま残ります。

割り当てられない場合は、379本を `/view/page/` 形式に一括置換し、**57ファイルを
貼り直す**ことになります。置換自体は自動化できますが、貼り直しは手作業です。

**この1点の結果で、57ファイルを貼り直すかどうかが決まります。** 他の作業より
先に確かめる価値があります。
