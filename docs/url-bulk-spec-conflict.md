## 何を間違えたか

以前82件のアップロードが「デザインセット情報が取得できませんでした」で全部
失敗したとき、**「切替前だから」とだけ解釈して先へ進みました。** 形式が違って
いても同じ失敗の出方をします。あの時点で書き出しボタンを押していれば、
10,328行を組む前に分かっていました。

**書き出す機能が同じ画面にあることは、画面を見た日から分かっていました。**
読む順番を間違えただけです。

## 上限の件（こちらの二重の誤り）

一度「上限は200KB」と報告しましたが、**画面には `最大2MB / 最大20,000件` と
書かれています。** マニュアルのページを画面より優先したのが誤りでした。
そもそも投入しないので、どちらでも影響はありません。

## 作ったCSVをどうするか

`package/url-bulk/` の5本は**投入しません。** 消しもしません。理由は2つです。

- リダイレクトが期待どおりに働かなかったときの材料になる
- 「追加URL」として**きれいなURLを新しく付けたい**という話が出たときに、
  商品コードと商品名の対応表としてそのまま使える（B列とC列を差し替えれば
  正しい形になります）

ただし**切替の手順からは外します。** 当日やることは「適用してリダイレクトを
確かめる」だけになりました。
