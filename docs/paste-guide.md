# 貼り付け手順

デザインセット **`発見マーケット_移行版`** に、全部で **19箇所** 貼ります。

**⚠️ 貼っている途中でショップに影響は出ません。** 画面にこう書かれています。

> デザインセット一覧画面で「ショップに適用」ボタンを押さない限り、
> ショップには反映されません。

**`ショップに適用` は、全部貼り終えて確認したあとです。**

---

## 順番

**この順番で貼ってください。** ページはモジュールを呼ぶので、モジュールが
先です。逆にすると、プレビューを押したときに中身が空で出ます。

```
① モジュール 6件   ← ページから呼ばれる部品
② 全ページ共通 2件  ← CSS と JavaScript
③ ページ 11件      ← 最後。1枚ずつプレビューで確認
```

---

## ① モジュール（6件）

`モジュール管理` →「モジュール追加」。編集画面には入力欄が**2つ**あります。

```
モジュールID   [            ]  $module.
管理用名称     [                                    ]
```

**🔴 テンプレートが呼ぶのは `モジュールID` のほうです。** `<{$module.leftmenu}>`
の `leftmenu` がここに入ります。1文字でも違うと、**エラーにならずにその部分だけ
空**になります。`管理用名称` は一覧に出る見出しで、自由に付けて構いません。

| モジュールID | 管理用名称 | ファイル | 行数 | 中身 |
|---|---|---|---:|---|
| `header` | ヘッダー | `package/modules/header.tpl` | 110 | ヘッダーの文言・電話番号・送料の帯・トレンドキーワード |
| `leftmenu` | 左メニュー | `package/modules/leftmenu.tpl` | 264 | 左メニュー（予算で選ぶ・シーンで選ぶ・商品別カテゴリー） |
| `footer` | フッター | `package/modules/footer.tpl` | 191 | コラム・各種ご案内・会社情報 |
| `calendar1` | 営業日カレンダー（今月） | `package/modules/calendar1.tpl` | 74 | 営業日カレンダー（今月） |
| `calendar2` | 営業日カレンダー（翌月） | `package/modules/calendar2.tpl` | 69 | 営業日カレンダー（翌月） |
| `freespace_calendar` | 卓上カレンダー説明 | `package/modules/freespace_calendar.tpl` | 247 | 卓上カレンダーのカテゴリ（ct646）の説明と休業日 |

## ② 全ページ共通（2件）

`全ページ共通` を開きます。**CSS と JavaScript の2つの箱**があります。

| 箱 | ファイル | 行数 | 大きさ |
|---|---|---:|---:|
| CSS | `package/paste/all-pages.css` | 9,084 | 187KB |
| JavaScript | `package/paste/all-pages.js` | 258 | 11KB |

どちらも **箱の中で Ctrl+A → Ctrl+V** で丸ごと置き換えます。

**🔴 継ぎ足さないでください。** いまこの箱には、差し戻された版のコードが
入ったままです。下に足すと**古い版が動き続けます。**

消えるものが1つだけあります。Basics 標準のコード（CSS 2,326行 / JS 67行）で、
作り直していない4つのページ種別が使っていました。**この4つは現行サイトの
どこからもリンクされていません**（保存した公開ページ全部の `href` を調べました。
レビューは u-komi です）。もし開かれた場合、飾りの付かない素の見た目になります。

**🔴 プレビューボタンはありません。** この2つは**保存した時点で反映**されます。
`全ページ共通` にプレビューボタンが無いのは、そういう仕様だからです。故障
ではありません。

**🔴 CSSが入りきらない可能性があります。**
以前の箱は110KBで、今回は185KBです。**入るかどうかは貼ってみないと
分かりません。** エラーが出たら教えてください。その場合は、CSSをストレージに
置いて読み込む形に切り替えます（いま `gigaplus` の `default.css` を読んでいる
のと同じやり方です）。

## 貼り終えたら

**まだ `ショップに適用` は押さないでください。**

プレビューで次を見ます。手元では確かめようがなく、**実物を見ないと
決まらない**ものです。

| 見るもの | なぜ |
|---|---|
| **会社概要** | `$company.content` に見出しが含まれるか。含まれていたら「会社概要」が2回出ます |
| **特定商取引法** | 表に「サイト名称」「適格請求書事業者登録番号」の行が出るか。この2行はリファレンスの14項目に無く、管理画面のどれかの欄に手で書き足されている可能性があります |
| **商品詳細** | 数量欄の横に `＠…円（税別）…個入` が出るか（`$item.special_display`） |
| **商品詳細** | 説明文が1回だけか（2回出ていたのが山口様のご指摘です） |
| **左メニュー** | 営業日カレンダーが出るか |
| **トップ** | お知らせ・バナー・コラムが出るか |
| **最近チェックした商品** | 出るか。`$recently_item.*` は未確認の2件です |

**プレビューのURLをこちらに送っていただければ、あとは私が確認します。**
1件ずつ目で見ていただく必要はありません。
