## 切替前に貼り終えておくもの — 5枚だけ（2026-09-05 見直し）

一時は「フリーページ55枚の貼り直し＋テンプレート数枚」を切替前の必須に
していましたが、55枚は前提が違っていました。

結論は変わりませんが、**理由が違っていました。**

当時は「`freepages-url.csv` が旧URLを追加URLとして登録するから」と書きました。
**その仕組みは使えません**（`/html/` は予約語）。正しい理由は、
**プラットフォームが旧URLを自動でリダイレクトするから**です
（[url-bulk-spec-conflict.md](url-bulk-spec-conflict.md)）。

貼り直しは正規URLで直接リンクするための整理であって、リンク切れを防ぐための
ものではありません。

**ただしCSV投入が前提です。** URL一括設定は切替後にしか通らないので、
CSVを入れないまま放置すれば、この55枚の中のリンクは404になります。

## 🔴 対応表に入っていない旧URLが3本あります

サイトマップに載っていて、URL一括設定のCSVに入っていないURLです。**切替後に
404になります。**

```
/html/company.html         サイトマップ有
/html/ordercontract.html   サイトマップ有
/html/info.html            サイトマップ有
```

いずれも**ページ種別**（会社概要／特定商取引法／利用案内）に変わったもので、
フリーページでも独自ページでもありません。URL一括設定の「URLタイプ」は
1=商品 / 2=カテゴリ / 3=独自ページ / 4=フリーページ の4種で、**ページ種別に
当てはまるものがありません。**

`/html/privacy.html` はサイトマップに載っていないので対象外です（フッターの
JavaScriptから開くポップアップのため）。

## ct646 の営業日カレンダー — 対応しました（2026-09-05）

判断待ちにしていた3案のうち、**B（モジュール1件）**で実装しました。

```
package/modules/category_calendar.tpl    営業日カレンダー2か月分
category.tpl                             <{if $category.code == 'ct646'}> で呼ぶ
```

### なぜBか

カレンダーは**毎月の更新が要ります**（いまも同じです）。テンプレートに
埋め込むと、更新のたびに270行のカテゴリページを貼り直すことになります。
モジュールなら、5KBのファイル1件を開いて表を直すだけです。

他の606カテゴリでは呼ばれません。

### 商品25枚は持ってきていません

元のフリースペースには、卓上カレンダー商品を25枚並べた表もありました。
**価格を直書きした写し**なので、価格改定や品切れのたびに実際と食い違います。

カテゴリページ本体が `$category.item.list` で実際の商品を、実際の価格と在庫で
出します。**古い写しを抱えるより正確です。**

これは内容の削減に見えますが、**同じ商品が、より正確な形で出ます。**
残したのは、プラットフォームに作れないカレンダーの方だけです。

### 貼り付け

モジュール管理 →「モジュール追加」→ 管理用名称 `category_calendar` →
`package/modules/category_calendar.tpl` の全文。

そのあと `商品カテゴリー` に `package/templates/category.tpl`（271行）を
貼り直してください。
