# 切替当日の手順書

## なぜ手順書が要るのか

URL一括設定は**適用中のデザインセットしか見ません**。フリーページ82件を
切替前に投入しようとして、全件が「デザインセット情報が取得できませんでした」
で失敗しました。

つまりURLの引き継ぎは、**切替を実行した後にしかできません**。

```
「ショップに適用」を押す
        ↓
    この瞬間から旧URLが404
        ↓
    CSVを3本アップロード
        ↓
      復旧
```

**その隙間の長さは、作業する人の手の速さで決まります。** 10,101件のURLが
その間ずっと404です。だから手順を先に決めておきます。

## 前提（切替の前に終わっていること）

- [ ] フリーページ55枚・トップ・フッター・CSSの貼り直し
- [ ] **デザインセットの保存枠を1つ空け、現行デザインを保存**
      ─ いま5枠とも満杯で、ワンクリックで戻せません。ZIPは記録であって
        復元ボタンではありません。**これが唯一の切り戻し手段です**
- [ ] 3本のCSVをデスクトップなど、すぐ選べる場所に置く
      `products-url.csv` / `categories-url.csv` / `freepages-url.csv`
- [ ] 2つの画面を別タブで開いておく
      ① クリエイターモードのデザインセット一覧
      ② URL一括設定

## 当日の手順

### 1. 適用（0分）

タブ①で「発見マーケット_移行版」の **ショップに適用**。

**この瞬間から、10,101件のURLが404になります。**

### 2. CSVを3本アップロード（目標5分以内）

タブ②に切り替えて、続けて3本。**商品が最優先**です。件数が最も多く、
検索からの流入も注文も、ここに集まります。

| 順 | ファイル | 件数 |
|---:|---|---:|
| 1 | `products-url.csv` | 9,513 |
| 2 | `categories-url.csv` | 606 |
| 3 | `freepages-url.csv` | 82 |

各アップロード後に「成功◯件／失敗◯件」が出ます。**失敗が出たら、そこで
止めて記録**してください。3本目まで進めてから戻ると、原因が混ざります。

### 3. 目視確認（10分）

新しいタブで、次を順に開きます。**旧URLで開くこと**が確認の要点です。

```
https://www.isp-sp.com/shopdetail/000000003919/     商品
https://www.isp-sp.com/shopbrand/003/003/X/         カテゴリ
https://www.isp-sp.com/html/page9.html              フリーページ
https://www.isp-sp.com/                             トップ
https://www.isp-sp.com/view/cart                    カート
```

上3つが**404にならずページが出れば、URLの引き継ぎは成功**です。

### 4. 機能の確認（15分）

見た目ではなく、**動くかどうか**を確認します。

- [ ] 商品ページで色を選び、**価格が変わるか**（オプション価格）
- [ ] **カートに入れる**が動くか
- [ ] カートで数量を変更できるか
- [ ] **見積依頼フォーム**が開くか（この店舗の主要な受注経路です）
- [ ] スマホでサブ画像が**スワイプ**できるか
- [ ] レビューが表示されるか（u-komi）

## 切り戻す判断

次のどれかなら、**迷わず戻してください**。

- 商品ページで価格が出ない、またはカートに入らない
- CSVの失敗が大量に出て、旧URLが404のまま
- 見積依頼フォームが開かない

**戻し方**: デザインセット一覧で、事前に保存した現行デザインの「適用」。
これが「前提」の2つ目を必須にしている理由です。

## 切替後にやること

- [ ] `robots.txt` が404です（現状から続く問題）。サイトマップの場所を書く
- [ ] Search Console に新しいサイトマップを送信
- [ ] お知らせ100件のURL（`/view/news/日時`）を確認し、対応を決める
      ─ **URL一括設定の対象外**で、旧URLから機械的に導けません
- [ ] 山口様に、単価順が失われたことをお伝えする
