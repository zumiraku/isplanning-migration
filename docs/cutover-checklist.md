## 切り替えで変わること（お客様にお伝えください）

### 1. スマホの見え方

いまスマホは `/smartphone/` の**専用サイト**に飛んでいます。切り替え後は
**飛ばなくなり、PCと同じページがレスポンシブで**出ます。iPhoneの名乗りで
確認済みです。ご依頼の「レスポンシブ」はこの形ですが、**現行のスマホ専用
サイトとは見た目が変わります。**

### 2. 商品ページの2つの枠が空になります

```
枠2  販売単位／見積依頼／名入れ／熨斗／包装 の可否表
枠3  名入れ料金・範囲等の表 または FAX注文用紙のご案内
```

MakeShop の「追加商品画像の説明文」で、クリエイターモードでは
**画像が登録されている商品でしか取り出せません。** この店舗は画像を入れずに
説明文だけ使っています。商品詳細のタグ123個を実データで全部調べ、
**他に取り出す手段はありませんでした。**

**対処**: 商品CSVで「追加画像説明文2/3」を「商品説明2/4」へ移します。
テンプレートは既にその2つを見ているので、移した瞬間に出ます。
**切り替えのあとに実行します**（先に流すと、切替までのあいだ現行サイトに
表が二重に出るため）。

```
1. ショップに適用
2. node tools/cdp/csv-upload.js tools/cdp/csv/test-one.csv     1商品で試す
3. プレビューで表が出ることを確認
4. node tools/cdp/csv-upload.js tools/cdp/csv/move-captions.csv  残り9,635商品
```

控え: `tools/cdp/csv/20260909181742.csv`（9,643商品・書き換え前）

### 3. 触っていない4ページ種別

商品レビュー一覧・投稿／まとめ買い割引／会員制・年齢確認。
**配信HTMLからは1本もリンクされていません**（`/view/review` 0件、
`/view/bulk` 0件）。直接URLを叩いたときだけ素の見た目になります。
