## 権限についてのお願い

現在いただいているサブ管理者アカウントで操作できる機能を確認したところ、
**全124機能のうち61機能**が利用可能で、残りは権限がかかっている状態でした。

このこと自体はセキュリティ上むしろ適切な設定だと思うのですが、
移行作業に必要な機能がいくつか含まれておりまして、
このままですと作業を進められない部分が出てまいります。

### とくに必要なもの

| 機能 | なぜ必要か |
|---|---|
| 商品管理 → 商品一覧 / 商品設定 | 商品ページの作りを確認するため |
| 商品管理 → 商品データダウンロード | 「スマホ用の商品説明」が入力されている商品を洗い出すため。**この欄はクリエイターモードでは使われなくなる**ため、事前に本文へ移しておく必要があります |
| 商品管理 → カテゴリ設定 | 607カテゴリのタイトル・説明文を確認するため。**こちらも切り替え後に設定できなくなる**部分です |
| 商品管理 → オプショングループ／名入れグループ | 商品詳細ページの価格計算・名入れの仕組みを確認するため。今回の移行で作り直しが必要な、いちばん重要な部分です |
| 注文管理 → 見積書一覧 | 後述のとおり、お使いかどうかの確認のため |
| 分析・販促管理／ショップ構築の各設定 | アクセス解析タグ・広告タグの確認のため。移行時にタグが外れると、広告の効果測定が止まってしまいます |

### ご対応方法は2通りあります

- **案A：必要な機能だけを追加していただく**（上記の一覧をお渡しします）
- **案B：一時的に管理者権限をいただく**

**作業のスムーズさだけで言えば案Bが確実です。**
今後また別の機能が必要になった際に、そのつどお願いする手間がなくなるためです。

ただ、パスワード等をお預かりしている立場で申し上げるのも何ですが、
外部の人間に強い権限をお渡しすることにご不安があるのは当然かと思います。
**案Aでまったく問題ございません。** 山口様がやりやすい方をお選びください。

### お約束

いずれの場合も、**こちらから設定を変更することはいたしません。**
現段階で行うのは「確認」と「控えの取得」だけです。
実際に何かを変更する必要が出てきた場合は、必ず事前にご相談し、
ご了承をいただいてから作業いたします。
