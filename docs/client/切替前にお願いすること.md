# 切替の前にお願いすること — 3つだけ

所要 15分ほど。**切替の当日でなくて構いません。**

---

## 1. 古いバックアップを1つ消す

新しいデザインを保存する枠が5つとも埋まっていて、**いまの見た目を保存できません。**
これが唯一の「元に戻す」手段です。

**1-1.** ブラウザで次を開く

```
https://console.makeshop.jp/design/editor?shopId=isplanning
```

**1-2.** 「デザイン設定画面一覧」という枠の **右下**、フロッピーの絵が付いた
グレーのボタン **`💾 デザイン一括バックアップ画面へ`** を押す

**1-3.** 表の1行目 **`デザインセット_20150203`（2015/02/03）** の
**右端の ✕** を押して消す

> 消してよいことは山口様からご承認いただいています（2026-09-08）。

---

## 2. いまの見た目を保存する

**2-1.** 同じ画面の上のほう、**`💾 適用中のデザインを一括保存する`** を押す

さっきまで押せなかったボタンが、枠が空いたことで押せるようになります。

**これが切り戻しのボタンになります。** 何かあったら、この保存したものを
「適用」すれば元通りです。

---

## 3. フリーページを3枚だけ貼り直す

山口様が商品を差し替えてくださった **page3・page72・page79** の3枚です。
管理画面に入っているのは差し替え前の版なので、そのままだと消えた商品を
指したままになります。

**3-1.** ブラウザで次を開く

```
https://console.makeshop.jp/design/editor?shopId=isplanning
```

**3-2.** ダークバー（黒い帯）の右端 **`クリエイターモード編集画面へ ›`** を押す

**3-3.** **「発見マーケット_移行版」** のカードの **✎（鉛筆）** を押す

**3-4.** 左メニューの下のほう、区切り線の下にある **`フリーページ管理`** を押す

**3-5.** 一覧から **page3** を開く

**3-6.** メモ帳で次のファイルを開く

```
C:\Users\Administrator\Documents\my-work\isplanning-migration\package\freepages\page3.html
```

**3-7.** メモ帳で **Ctrl+A** → **Ctrl+C** → フリーページの入力欄で
**Ctrl+A** → **Ctrl+V** → **`保存`**

**3-8.** 同じことを **page72** と **page79** でも行う

```
package\freepages\page72.html
package\freepages\page79.html
```

---

これで切替の準備は終わりです。あとは夜8時以降に20分ほどです。
