## 各列の値

| 列 | 商品 | カテゴリ | フリーページ |
|---|---|---|---|
| URLタイプ | 1 | 2 | 4 |
| システムURL | `/view/item/<コード>` | `/view/category/ctNNN` | `/view/page/pageNN.html` |
| 名称 | 商品コード | カテゴリ名 | ページ名 |
| canonical属性 | 0 | 0 | 0 |
| 追加URL | `/shopdetail/<コード>/` | `/shopbrand/…` | `/html/pageNN.html` |
| noindex設定 | 0 | 0 | 0 |

**canonical を 0 にしている**のは、移行後に残るのが `/view/…` 側だからです。
1 にすると、いずれ捨てるURLを「正」だと検索エンジンに宣言することになります。

**商品の名称にコードを入れている**のは、9,514件分の商品名が手元にないからです。
この欄は管理用で公開されません。空にして必須だった場合、9,513行が一度に
落ちます。フリーページで82件が全滅したときのように原因の切り分けに時間を
取られるより、確実に埋まる値を入れておく判断です。

## カテゴリのコード対応について

商品はコードが同じなので機械的ですが、**カテゴリは旧新でコード体系が違います**。

```
旧  /shopbrand/003/001/X/
新  /view/category/ct5
```

対応表の出どころは、クロール時に各カテゴリページが持っていた
`rel="alternate"` です。スマホ版URLに `category_code=ctNNN` が入っていました。
**SPサイトは移行で消えますが、消える前に記録していたおかげで対応が取れます。**

607件中606件。取れなかった1件は `rel="alternate"` を持たないページで、CSVには
含めていません。推測でct番号を当てると、**別のカテゴリのURLを別のカテゴリに
割り当てる**ことになります。

## 4本目 — pagetypes-url.csv（3行）

**通るかどうか分かりません。** 分けてあるのはそのためです。

サイトマップに載っているのに、他の3本でカバーできないURLが3つあります。

```
/html/company.html         → /view/company
/html/ordercontract.html   → /view/contract
/html/info.html            → /view/guide
```

いずれも**ページ種別**（会社概要／特定商取引法／利用案内）に変わったもので、
フリーページでも独自ページでもありません。URL一括設定の「URLタイプ」は
1=商品 / 2=カテゴリ / 3=独自ページ / 4=フリーページ の4つしかなく、
**ページ種別に当てはまるものがありません。**

3 を当ててあります。通れば3本救えます。**弾かれたらその3本が404**です。

### 単独で投入してください

**他の3本と混ぜないでください。** フリーページ82件を投入したとき、
1件の問題で82件すべてがエラーになりました。3行を分けておけば、弾かれても
10,201行には影響しません。

### /html/privacy.html は入れていません

サイトマップに載っていないためです。フッターのJavaScriptから開くポップアップで、
通常のリンクがありません。検索エンジンも到達していません。

## 5本目 — news-url.csv（101行）

**「打ち手なし」と書いていたものが、救えるようになりました。**

```
/new/2013-08-01-173816.html  →  /view/news/20130801173816
       ~~~~~~~~~~~~~~~~~
```

旧URLそのものが日時でした。ハイフンを取るだけです。**旧URLを一度も見ずに
「導出できない」と書いていました。**

### マニュアルの表記

公式には `/view/news/yymmddhhmmss` とあります。`yy` を西暦2桁と読んで
`130801173816` を試し、404。**実際は西暦4桁**です。

```
130801173816    HTTP 302 → /error/404.html
20130801173816  HTTP 200
```

### 101件すべて確認済み

プレビューで全件開いて、100記事が HTTP 200。残り1件は `/new/index.html` で、
`/view/news/list` です。推測ではありません。

### URLタイプは推測です

1=商品 / 2=カテゴリ / 3=独自ページ / 4=フリーページ の4つに、お知らせに
当たるものがありません。**3 を当ててあります。**

通れば101本。弾かれても、**新URLが分かっていること自体が資産**です。
メイクショップのサポートに転送を依頼する材料になります。

**単独で投入してください。**
