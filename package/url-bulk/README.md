# URL一括設定 — アップロード用CSV

生成: `sh tools/build-url-csv.sh`
ファイル: `freepages-url.csv`（82行、UTF-8 BOM付き、11KB）

## これが何をするか

フリーページ82枚に、**移行前と同じ `/html/pageNN.html` を「追加URL」として
持たせます。** システムURL（`/view/page/pageNN.html`）と併存し、どちらでも
開けるようになります。

通れば、こうなります。

- 貼り終えたページの中にある **379本のリンクを1本も直さなくてよい**
- **57ファイルの貼り直しが不要**
- 82ページが13年かけて積み上げた検索評価が途切れない
- 外部サイトから `/html/...` に張られたリンクも生き続ける

## 列と値

管理画面のマニュアルどおりです。

| 列 | 値 | 意味 |
|---|---|---|
| URLタイプ | `4` | フリーページ（クリエイターモード） |
| システムURL | `/view/page/pageNN.html` | 先頭スラッシュあり・ドメインなし |
| 名称 | 管理画面の独自ページ一覧の題名 | |
| canonical属性 | `0` | システムURL側を正とする |
| 追加URL | `/html/pageNN.html` | 移行前のURL |
| noindex設定 | `0` | インデックスされる |

## canonical を `0` にした理由

同じ内容が2つのURLで開ける状態になるので、**どちらを正とするかを明示しないと
重複コンテンツ**になります。

- `0` → `/view/page/...` が正。`/html/...` はそこへ集約される
- `1` → `/html/...` が正

**移行後に残り続けるのは `/view/page/...` のほう**です。`1` を選ぶと、いずれ
捨てるURLを「正」だと検索エンジンに宣言することになります。ですので `0`。

`/html/...` を使い続けたいという判断であれば `1` に変えられますが、その場合は
ベーシックモードを畳んだ後も旧URLを維持し続けることになります。

## 検証済み

- 82行（過不足なし）
- 全行が正しい形式
- システムURLと追加URLのページ番号が全行で一致
- ページ番号の重複なし

## 貼り方

1. `https://console.makeshop.jp/settings/feature-catalog?shopId=isplanning`
2. 検索欄に `URL` と入力
3. 「URL一括設定」の「開く」
4. 「CSVアップロード」の「CSVファイルを選択」で `freepages-url.csv` を選ぶ
5. 「アップロード」

⚠️ 画面下の「URL設定データを削除」は押さないでください。

## 通らなかった場合

エラーの文言をそのまま控えてください。列数・値の範囲・URLの重複など、
どれに引っかかったかで次の手が変わります。

`/html/pageNN.html` が「ベーシックモードの独自ページと衝突する」と言われる
可能性があります。その場合は、ベーシックモード側の独自ページを非公開にしてから
再試行することになりますが、**それは切替と同時に行うべき操作**なので、
先に判断が要ります。
