## 🔴 貼る前に知っておくこと

### 1. 類推で書いたタグが56個あります

`sh tools/check-smarty.sh` が毎回一覧を出します。確認済み156・類推56。

類推は「一覧側に `cart_entry_url` があるから詳細側にもあるはず」という
たぐいの推測です。当たっている可能性は高いですが、**Smartyは間違ったタグを
何も出さずに黙って捨てます**。エラーも空白も出ず、価格やボタンが消えるだけです。

貼った直後に、各ページを**プレビューで目視**してください。消えている要素が
そのままリストの答えになります。

### 2. 内部リンクは旧URLのままです

フッターやトップの `/html/pageNN.html` は、クリエイターモードでは
`/view/<name>` になります（C33）。**URL一括設定で現行URLを再現できるか**が
未検証なので、あえて旧URLのまま置いています。検証の結果しだいで一括置換
します。先に `page82` で試すのが安全です。

### 3. 単価順は再現していません

`[SORTPRODUCT]`（単価順）にクリエイターモードの対応がありません。並び替えは
新着・おすすめ・価格高・価格低・商品名の5つです。粗品店では効く欠落なので、
黙って埋めずに空けてあります。山口様のご判断待ちです。
