# タグ調査ページ — 使い捨て

`$item.caption_1`（山口様の「＠100円（税別）100個入」）が実在するかを、
**1回のプレビューで決着させる**ためのページです。公開用ではありません。

## なぜ必要か

切替中の実ページを全文検索しても「単価＠238」は0件でした。**こちらが使った
どのタグからも出ていません。** タグ台帳では `$item.caption_1` が
`assumed`（推定）のままで、切替前に検証すべきものでした。それをせずに
切り替えたのが、山口様のご指摘のうち最も重いものの原因です。

## 2つある理由

| ファイル | 中身 | 使う場面 |
|---|---|---|
| `detail-probe.tpl` | `foreach` で `$item` のキーを**全部**吐かせる版 | **まずこちら** |
| `detail-probe-safe.tpl` | `foreach` を抜いた版 | 上がエラーになったときだけ |

`foreach` はこの環境で使われた実績がありません。使えれば `$item` の正しい
キー名が一覧で出るので、候補を当てにいく必要そのものが消えます。使えない場合は
テンプレートのコンパイルごと失敗するので、**予備版を先に手元へ置いてから**
始めます。往復を増やさないためです。

修飾子（`|@count_characters` など）は使っていません。**無い修飾子が1つあると
ページ全体が落ちて、調査そのものが空振りします。**

## 安全性

デザインセット「発見マーケット_移行版」の中を編集するだけです。
プラットフォームが画面に明記しています。

> デザインセット一覧画面で「ショップに適用」ボタンを押さない限り、
> ショップには反映されません。

いま公開中はベーシックモードで、このデザインセットは適用されていません。
