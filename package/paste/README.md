# 管理画面に貼るもの

**このフォルダのファイルを、そのまま Ctrl+A → Ctrl+V で貼れます。**

ただし、ここに入るファイルは `tools/make-paste-file.js` で作ります。
最初から入ってはいません。理由は下に書きます。

## なぜ、そのまま貼れるファイルを用意するのか

CSS と JavaScript の箱には、**Basics 標準のコードが同居しています。**
そして、こちらのブロックの位置が2つで逆です。

```
CSS          Basics標準 2,326行  →  こちら 955行      （こちらが後ろ）
JavaScript   こちら 409行        →  Basics標準 67行   （こちらが前）
```

JavaScript を逆にすると、Basics の1行目が `$`（jQuery）を呼んで落ち、
**こちらのコードは1行も動きません。** 2026-09-05 に実際にそうなりました。
CSS を逆にすると、Basics の指定がこちらに勝って見た目が壊れます。

**この順番を毎回思い出しながら、部分的に選択して貼る**という作業は、
いつか必ず間違えます。だから道具にしました。

## 作り方

1. コンソールの箱の中身を全部コピーして、ファイルに保存する
2. 道具に渡す
3. 出てきたファイルを、箱に Ctrl+A → Ctrl+V で戻す

```sh
node tools/make-paste-file.js js  <保存したファイル>
node tools/make-paste-file.js css <保存したファイル>
```

こちらのブロックの範囲は、**前に貼った版の中身そのもの**で探します。
行数や目印からの推測ではありません。見つからなければ**何も書き出さずに
止まります** — 範囲が分からないまま並べ替えると、Basics のコードを
消しかねないからです。

## 箱の行数と、配信される行数は一致しません

プラットフォームが後ろに自動で足すためです。

```
CSS         箱 3,261行  →  配信 3,297行（+33行）
JavaScript  箱   433行  →  配信   482行
```

**行数が合わないことは、失敗の証拠ではありません。** 確認するときは、
こちらのブロックの最終行がどこで終わっているかを見てください。
