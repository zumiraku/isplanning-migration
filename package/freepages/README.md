## 貼り方（1ページあたり）

1. `MANIFEST.csv` の上から順に1行取る
2. クリエイターモード › **フリーページ管理** › **ページ追加**
3. **ページURL** ＝ MANIFEST の `page_url` 列（例 `page9.html`）
4. **ページ名** ＝ MANIFEST の `title` 列
5. **ステータス** ＝ 公開
6. `<slug>.html` をメモ帳で開き `Ctrl+A` → `Ctrl+C` → HTML欄に貼り付け
7. 保存

## URLについて

ページURLは `/view/page/` が固定で、その後ろだけ指定できます。使える文字は
**半角数字・半角英小文字・ハイフン・ドット・アンダーバー**。**スラッシュは
使えません。**

```
現在   /html/page9.html
移行後 /view/page/page9.html
```

`.html` を残しているのは、82件の対応を目で確認するときに
`page9.html → page9.html` なら一瞬で正しいと分かるからです。
