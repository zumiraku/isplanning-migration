# フリーページ 86枚 — 貼り付けパッケージ

生成: `sh tools/build-freepage-package.sh`

## 中身

| | |
|---|---|
| `<slug>.html` | **フリーページのHTML欄にそのまま貼るもの。** 切り出しは不要です |
| `MANIFEST.csv` | slug / タイトル / 現在のURL / バイト数 / 注意書き。**被リンクの多い順** |

`<html>` や `<head>` は入っていません。本文だけです。テンプレート側が包みます。

## なぜ被リンク順なのか

86枚を一度に入れ切れるとは限りません。途中で止まったとき、**サイト内で最も
参照されているページから出来上がっている**状態にしたいからです。

```
29本のリンク先  page9   商品別カテゴリー
28本            page8   シーンで選ぶ
27本            page4   SP SOURCE カタログのご案内
26本            page5   季節で選ぶ粗品
17本            page2   粗品の名入れ・包装・熨斗のご案内
```

上位5枚が入った時点で、127本の内部リンクの行き先が確保されます。50音順や
番号順で始めると、この5枚は真ん中あたりまで出てきません。

## 手順（1ページあたり）

1. `MANIFEST.csv` の上から順に slug を1つ取る
2. 管理画面 › クリエイターモード › **フリーページ管理** で新規作成
3. **名前** ＝ MANIFEST の `title` をそのまま
4. **URL** ＝ 下の「URLの決め方」を参照
5. `<slug>.html` を開き `Ctrl+A` → `Ctrl+C` → HTML欄に貼り付け
6. 保存

## 🔴 URLの決め方は、まだ決められません

現在は `/html/pageNN.html`、クリエイターモードの既定は `/view/<name>` です
（C33）。**URL一括設定で現在のURLを再現できるかどうかが未検証**で、その答えに
よって、ここに入れるべき値が変わります。

- 再現できる → 現在のURLをそのまま維持でき、内部リンク646本は無傷
- 再現できない → 646本の書き換えと、サイトマップとSearch Consoleの手当て

**先に `page82` の1枚で試してください。** スマホ用カレンダーで、公開リンクが
どこからも張られていない予備ページです。ここで壊しても誰にも影響しません。
試す価値があるのは次の2点です。

1. 任意URLに **スラッシュ** を含められるか（`/html/page82.html` のように）
2. 任意URLに **`.html`** を付けられるか

両方通れば、86枚すべて現在のURLのまま移せます。

## 4枚は フリーページ ではありません

`company` `info` `ordercontract` `privacy` は独自ページではなく、それぞれ専用の
設定画面を持っています。エディタ左メニューの **会社概要 / 利用案内 /
特定商取引法 / プライバシーポリシー** に、それぞれのHTMLを入れてください。
MANIFEST の `note` 欄にも書いてあります。
